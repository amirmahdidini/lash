# Lash Vibe By Roya - آنلاین رزرو و پنل مدیریت

این پروژه شامل فرانت‌اند و بک‌اند کامل سیستم مدیریت و رزرو نوبت سالن زیبایی مژه **Lash Vibe By Roya** می‌باشد.

## 🚀 ویژگی‌های کلیدی
1. **حذف تمامی کلیدها و گزینه‌های پنل مدیریت از وب‌سایت عمومی**: کاربران عادی هیچ دکمه‌ای برای ورود به پنل مدیریت مشاهده نمیکنند.
2. **آدرس اختصاصی پنل مدیریت**: دسترسی به پنل مدیریت فقط از طریق آدرس `http://localhost:3000/admin-panel-secret` مقدور است.
3. **رمز عبور پنل مدیریت**: `amirmahdiisformine`
4. **تأیید یا لغو سفارشات رزرو شده**: مدیر سالن می‌تواند وضعیت رزروها را از «در انتظار تأیید» به «تأیید شده» یا «لغو شده» تغییر دهد.
5. **بستن دستی ساعات رزرو**: امکان غیرفعال کردن و بستن دستی سانس‌ها و ساعت‌های خاص در هر تاریخ برای جلوگیری از رزرو مشتریان.
6. **افزودن و ویرایش قیمت و خدمات مژه**: همراه با **آپلود تصویر اختصاصی** که بک‌اند آن به صورت خودکار تصویر را به ابعاد دقیق **500x500 پیکسل** بر برش می‌دهد.
7. **ارسال و ذخیره‌سازی داده‌ها**: تمامی اطلاعات رزرو، سانس‌های بسته شده و خدمات به همراه Node.js در فایل داده ذخیره می‌شوند.

---

## 🛠️ نحوه اجرا و راه‌اندازی

1. **نصب نیازمندی‌ها (Node.js)**:
   ابتدا Node.js را روی سیستم خود نصب داشته باشید، سپس ترمینال را در پوشه پروژه باز کنید و دستور زیر را اجرا کنید:
   ```bash
   npm install
   ```

2. **اجرای سرور**:
   ```bash
   npm start
   ```

3. **دسترسی به سایت عمومی**:
   مرورگر خود را باز کرده و به آدرس زیر بروید:
   `http://localhost:3000`

4. **دسترسی به پنل مدیریت سالن**:
   به آدرس محرمانه زیر بروید:
   `http://localhost:3000/admin-panel-secret`
   * **رمز ورود**: `amirmahdiisformine`
